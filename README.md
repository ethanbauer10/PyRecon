# PyRecon
This is my final year project I created for my degree in Cyber Security

PyRecon is a multi-module recon suite built in python with 3 useful modules.

The tool includes:
- A port scannner (with both a speed and accuracy mode)
- A directory brute forcer
- A subdomain discovery module that uses host header injection

Make sure the requirements are installed before running the tool

It is also recommended to run this insdie a python virtual environment to save breaking system packages
